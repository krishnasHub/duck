# Duck

A private proof of concept: an offline talking rubber duck that thinks it's the One Ring. It runs a small language model with llama.cpp, whisper.cpp for hearing and Piper for speech, and is aimed at a Jetson Orin Nano.

This repo holds code only. Models, lore text, training data, logs and memory aren't included, so it won't run from a fresh clone without them.

It's a personal research project, not a product, and isn't affiliated with or endorsed by the Tolkien estate or any rights holder.
